VOICE READER — free text-to-speech extension (Chrome / Edge / Brave)

INSTALL (one time, about 1 minute)
1. Unzip voice-reader.zip somewhere you'll keep it (for example Documents/voice-reader).
2. Chrome: go to chrome://extensions   (Edge: edge://extensions)
3. Turn on "Developer mode" (top-right in Chrome, left sidebar in Edge).
4. Click "Load unpacked" and pick the unzipped "voice-reader" folder.
5. Pin it: click the puzzle icon in the toolbar, then the pin next to Voice Reader.
6. Refresh any tabs that were already open.

USE
- Highlight text and a "Read aloud" button pops up. Click it, pick a voice and speed, then press "Read with ...".
- Player: drag it anywhere (the position is remembered). Use it to play/pause, go to the previous or next sentence, change speed, or switch voice by clicking the avatar.
- Right-click highlighted text and choose "Read aloud", or right-click the page and choose "Read this page aloud".
- Shortcuts: Alt+Shift+R to read, Alt+Shift+P to pause/resume, Alt+Shift+S to stop.
- Click the toolbar icon to choose the default voice, speed, preview voices, or turn off the pop-up button.

VOICES
Aria, Sophie and Luna are female. Jarvis (British AI butler) and Max are male.
They use the free voices built into your browser and computer. For the best quality:
- Microsoft Edge on Windows has very natural "Online (Natural)" voices. Jarvis uses "Ryan", which sounds great.
- In Chrome, Jarvis uses "Google UK English Male".
- On a Mac, Jarvis uses "Daniel".
In the popup, open "Advanced" to pick the exact system voice for any of the five presets.

LIMITS
Browsers block extensions on their own pages (chrome:// pages, the Web Store and the built-in PDF viewer).
Google Docs draws its text in a way that page readers can't access, so use right-click > Read aloud there or copy the text.
